# Тестовое задание: Users Dashboard

## Построй дашборд со списком пользователей.

API: https://dummyjson.com/users
Документация: https://dummyjson.com/docs/users

## Реализации в проекте
1. Собран дашборд со списком пользователей на `React + TypeScript + Vite`.
2. Данные пользователей загружаются по API из `dummyjson` (`https://dummyjson.com/users`).
3. Реализован табличный вывод пользователей с колонками: ID, имя, телефон, email, дата рождения, локация, номер карты.
4. Добавлен поиск по нескольким полям: имя, фамилия, email, телефон, номер карты.
5. Сделана обработка пустых состояний таблицы:
   - если нет данных;
   - если по запросу ничего не найдено.
6. Подключена автопубликация в `GitHub Pages` через `GitHub Actions` (workflow: `.github/workflows/deploy-pages.yml`).
7. Фильтрацию оставил на фронтенде, потому что для тестового задания это быстрее и проще в реализации. В продакшен-проекте вынес бы фильтрацию на API, чтобы получать уже отфильтрованные данные и не загружать в браузер весь массив.
8. Добавлена форма создания пользователя с отправкой `POST` на `https://dummyjson.com/users/add`; после ответа API новый пользователь сразу отображается в таблице. Поля формы адаптивно скрываются на узких экранах по той же логике, что и колонки таблицы.
9. Добавлено контекстное меню строки таблицы: по клику возле курсора появляются действия редактирования выбранного поля (`PATCH /users/:id`) и удаления пользователя (`DELETE /users/:id`) с локальным обновлением таблицы после ответа API.


## Почему сделано именно так
- Базовая архитектура разделена на страницу, таблицу и хук поиска, чтобы логика фильтрации была изолирована и легко расширялась.
- Фильтрация выполнена через `useMemo`, чтобы не пересчитывать список без необходимости.
- Для GitHub Pages настроен корректный `base` в `vite.config.ts`, чтобы ассеты работали по адресу вида `/GabaHR/`.


## Инструкция по локальному запуску
1. Установить зависимости:
   `npm install`
2. Запустить dev-сервер:
   `npm run dev`
3. Открыть адрес из терминала (обычно `http://localhost:5173`).

## Сборка production-версии
1. Выполнить сборку:
   `npm run build`
2. Для локального просмотра production-сборки:
   `npm run preview`
